# Legacy TikTok ingestion tools

These scripts are retained for historical migration and investigation only. They are not part of the four active commerce-content-director execution modules and must not be selected for ordinary content planning, storyboard generation, final-video generation, or lifecycle work.

They use browser/CDP-oriented workflows and require their own authorization and maintenance review before reuse. Keep them isolated from the active `scripts/` directory so the current Skill's execution surface remains limited to the documented content-production pipeline.
