# 脚本内容来源

新任务以 [script-workbook-contract.md](../domain/script-workbook-contract.md) 的 Markdown 创作稿为内容来源。口播、时间、画面动作和衔接只在创作稿维护一次；执行 Prompt、请求、结果和状态写入 [execution-record-contract.md](../domain/execution-record-contract.md)。

Feishu 记录是查询与审核表面，执行记录是本地运行账本。二者都从创作稿或执行结果产生，不成为另一份可手工编辑的脚本。

脚本段落拥有内容语义：它写清这一段说什么、看见什么、如何进入和结束。Beat 只在复杂叙事需要时作为可选标签；Segment 是生成单元，两者不强制一一对应。

产品事实、主体、场景和结构锁拥有事实权威。模板只能提供可选行为参考，不能创建产品能力。Prompt 不能静默修改脚本动作、产品事实或结果；若需要改变，先修改创作稿并增加新修订。
