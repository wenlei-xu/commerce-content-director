# 内容母题、创意候选、内容策划任务与产品

内容策划任务承载已收敛的任务级方向与复刻证据；产品事实和产品素材统一按产品聚合到“产品”表的一条记录中。用户未明确说“复刻”时，默认按原创处理；产品必须直接从“产品”表查找，不要求通过内容策划任务的产品关联来定位。需要从大方向发散时，先在`内容母题`中记录方向，再由 AI 写入多个`创意候选`；只有入选候选才可创建一条原创内容策划任务。

## 1. Base 结构

所有表都位于“短视频内容创意库”Base（`app_token=QQ1ib0FTHahCUhstRH8cVx9in7S`）。

| 表 | table_id | 角色 |
| --- | --- | --- |
| `产品` | `tbl025LGPiG2WyGp` | 一条记录就是一个产品的完整事实、注意事项与图片资产包 |
| `内容策划任务` | `tblW0M6Td3rZm7L9` | 唯一的原创与复刻内容入口；用于调整、热更新和版本管理 |
| `内容母题` | `tblostUgRA3B19CY` | 一个大方向的输入和收敛控制；不进入分镜、审核或视频生成 |
| `创意候选` | `tbltUkkNOrgo7SgP` | AI 从母题扩散出的独立创意方向；入选后才可落地为原创任务 |
| `内容库` | `tblGPsdyzMG0o6zP` | 可审核、可生成的具体内容版本 |
| `最终成片` | `tblZZDu01Ib4OuHT` | 仅收录已完整生成、可发布的视频；每条成片关联一个内容版本 |
| `主体资产库` | `tbldo07eIN3HSFHi` | 可复用的人物、狗、猫等主体身份锚点；一条记录代表一个稳定主体 |

关联方向：`内容母题.产品 → 产品`；`创意候选.内容母题 ↔ 内容母题.创意候选列表`；`内容策划任务.来源创意候选 ↔ 创意候选.落地内容策划任务`；`内容策划任务.产品 → 产品`；`内容库.内容策划任务 → 内容策划任务`；`内容库.产品 → 产品`；`最终成片.内容版本 → 内容库`。复刻用的爆款视频是内容策划任务的直接附件，不另建视频资产记录。一个内容版本必须关联且只能关联一个内容策划任务。

`内容策划任务.主体资产 → 主体资产库` 与 `内容库.主体资产 → 主体资产库` 用于固定跨分镜的人物/宠物身份。主体资产记录应包含稳定的主体锚点图和身份描述；分镜生成时将其与产品锚点一起作为输入图，不要只在 prompt 里写“同一只狗/同一个人”。任务的 `主体资产` 为空时，不要求人工先绑定：从 `主体资产库` 自动筛选 `状态=可用` 且锚点、身份描述完整的匹配记录；按任务文本中的主体类型/角色、证明场景与默认场景打分，仍并列时按 `record_id` 稳定选择第一条。没有合格记录才停止。

## 2. 产品：唯一产品入口

人工日常只维护一条产品记录，并一次拖入对应附件；不需要为每张图片建记录、起 asset_id 或填写用途。

| 字段 | 用途 |
| --- | --- |
| `产品名称`、`产品ID`、`状态` | 标识与启停；只有 `可用` 产品可用于新内容 |
| `一句话产品定位` | 用一句可核实的话说明产品是什么，供标题和脚本理解产品 |
| `核心卖点` | 已确认、可被内容证明的卖点；一条一行或用编号分隔 |
| `目标人群`、`典型痛点`、`典型使用场景` | 面向谁、解决什么具体问题、在哪些真实场景使用 |
| `可用表达 / 可用宣称` | 可直接使用的已确认话术、材料或体验描述 |
| `禁用表达 / 禁用宣称` | 不能说的功效、价格、安全或夸张话术 |
| `产品硬事实与禁忌` | 产品结构、唯一交互路径、禁止动作；其优先级高于卖点与话术 |
| `生成注意事项` | 容易画错的结构、镜头和交互提醒；这是唯一注意事项来源 |
| `产品审核要求` | 产品专属验收标准，建议按 `PASS`、`WARN｜人工复核`、`FAIL` 分段；只补充产品特有审核边界，不覆盖全局安全、真实性、主体连续性、图板几何或最终成片规则 |
| `默认产品锚点` | 生成时优先使用的确认版产品图 |
| `产品三视图`、`产品细节图`、`产品场景图`、`其他产品素材` | 分类附件，可多选一次上传 |

每次内容创作前，读取所关联产品的全部字段和附件：先锁定硬事实与禁忌，再读取 `产品审核要求`（若为空则使用 skill 的严格默认审核），最后从核心卖点、人群、痛点、场景和可用表达中选择本条内容的论点；禁用表达必须排除。任何本地 `product-routes` 文件、旧资产记录或临时工作目录都不是产品事实来源。若产品记录为空、状态不是 `可用`、缺少默认锚点，或事实与策略冲突，生成前停止。`产品审核要求` 中的 `WARN｜人工复核` 必须原样保存到本地 package、质量报告和飞书审核备注，不得被静默当作 PASS。

## 3. 内容母题与创意候选

`内容母题`是“给一个大方向，让 AI 展开”的唯一入口；它不是任务、分镜或内容版本。填完一条母题后，明确要求扩散或点名该记录，AI 才会读取它并创建候选。`创意候选`不能直接进入审核、分镜或视频生成。

### 3.1 内容母题字段

| 字段 | 填写规则 |
| --- | --- |
| `母题名称`、`母题ID` | 便于识别的名称和稳定 ID；例如“独居养猫人的陪伴焦虑” |
| `产品`、`平台 / 账号` | 必填；候选和后续任务继承，不得由候选改写产品事实 |
| `大方向 / 营销目标` | 必填；描述问题、受众、商业目标或内容主题，但不强行写死钩子、剧情和卖点排序 |
| `期望候选数` | 必填，整数 3–12；AI 必须写入恰好这个数量的合格候选 |
| `收敛方式` | 必填，仅为`人工筛选`或`自动 Top 1`；前者等待人工，后者由 AI 评分后只创建一条任务 |
| `优先级` | 必填，仅为`高`、`中`或`低`；落地任务继承该值 |
| `创作要求` | 可选的风格、时长、场景或限制；不得与产品硬事实、规则或平台合规边界冲突 |
| `主体资产` | 可选；一旦候选使用跨镜头连续主体，必须关联可用主体资产 |
| `扩散状态` | `待扩散` → `候选待确认`（人工筛选）或`已收敛`；只允许按此状态机推进 |
| `入选候选` | 人工筛选时必须只关联一条已标记`入选`的候选；自动收敛由 AI 写入 |
| `备注` | 可选人工补充 |

### 3.2 创意候选字段

每条候选必须关联一个母题，并完整填写`目标人群`、`痛点`、`核心卖点`、`钩子`、`叙事节奏`、`证明场景`、`核心创意`和`差异化标签`。六项评分`产品贴合分`、`转化强度分`、`证据密度分`、`UGC真实感分`、`可执行性分`、`合规性分`均为 1–5 分；`综合评分`为六项的算术平均值，`评分说明`必须解释取舍。

`候选状态`只能是`备选`、`入选`或`淘汰`。`任务创建状态`只能是`未创建`、`已创建`或`创建受阻`。候选的`落地内容策划任务`为空时不得进入分镜；同一候选只允许关联一条落地任务。

### 3.3 扩散与收敛

1. 人工在`内容母题`填写必填项，设为`待扩散`，再明确要求 AI 扩散。
2. AI 读取母题、产品、可选主体资产和原创规则，生成并写入指定数量的`创意候选`，全部先标为`备选`。
3. `人工筛选`：AI 将母题改为`候选待确认`并停止。人工把一条候选标为`入选`，同时写入母题的`入选候选`，再明确要求创建任务。
4. `自动 Top 1`：AI 按综合评分及规定的平分规则选一条，更新状态并创建任务。
5. AI 将入选候选逐字段映射为`内容策划任务`，设置`策划模式=原创`、关联产品和`来源创意候选`。后续流程完全沿用现有原创分镜、附件验证和人工审核。

不得在扩散阶段创建`内容库`记录、生成分镜图、提交 Flow2API Job，或为未入选候选创建任务。

## 4. 内容策划任务

内容策划任务是人工维护的轻量输入，不是分镜或内容版本。显式复刻时，读取任务的`策划模式`与复刻素材来确定复刻程度；未说“复刻”时默认原创，任务仍用于承载原创专用字段，但不是产品检索入口。每条任务均填写`任务名称`、`策划模式`、`产品`、`平台 / 账号`、`优先级`；`主体资产`在表结构上可选，填写时优先使用；为空时由 agent 从主体资产库自动选择可用匹配记录；`创作要求`可选。

| 策划模式 | 必填输入 | 允许使用的参考证据 | 原创专用字段 |
| --- | --- | --- | --- |
| 原创 | 产品、平台/账号、原创专用字段；若画面使用跨镜头主体，则必须有可用主体资产（任务已绑定或由 agent 从主体资产库自动选择） | 不使用参考视频 | `目标人群`、`痛点`、`核心卖点`、`钩子`、`叙事节奏`、`证明场景`、`核心创意` |
| 钩子复刻 | 产品；`钩子复用素材`或`爆款视频`/`爆款视频链接` | 钩子复用素材，或爆款视频 `0–3 秒` | 不使用来源视频正文作为原创方向 |
| 结构复刻 | 产品；`爆款视频`或`爆款视频链接` | 全片的阶段时长、叙事功能、证明目标与转场目的 | 不复用任何具体画面、动作、文案或音频 |
| 全量复刻 | 产品；`爆款视频`或`爆款视频链接` | 整条爆款视频 | 不适用 |

原创专用字段只在`策划模式=原创`时参与创作；复刻专用字段（`爆款视频`、`爆款视频链接`、`钩子复用素材`）只在三种复刻模式时读取。不得以空白复刻字段代表原创，也不得让原创任务引用复刻素材。`主体资产`可为空；只要脚本、证明场景或分镜使用同一人物/动物/其他可识别主体跨两个以上镜头或跨段连续出现，就从主体资产库自动选择一条可用记录并在内容版本中记录映射；没有主体锚点和身份描述时才停止。若视频超过飞书单文件 20 MB 限制，请填写链接或通过飞书界面上传。

当用户要求根据一个明确的内容策划任务制作、调整或热更新内容时，系统读取该任务、直接检索的产品记录、主体资产与原创规则，并创建新的内容库版本。不得在正常分镜生成中回写、补全或新建内容策划任务；唯一例外是按第 3.3 节从已入选候选创建原创任务。任务内容的其他修改由人工或用户明确授权的任务维护操作完成。

## 5. 内容版本规则

每个版本是 `内容库` 中独立、可审核的 `content_id`。

- 每个版本均填写 `内容策划任务`、`产品`和`版本号`（如 v1/v2/v3）。复刻版本的`改编角度`必须等于任务的`策划模式`；原创版本填写`创作模式=原创`、原创创意字段与规则快照。
- 既有脚本、分镜、提示词、附件和审核字段。

同一内容策划任务下的版本只能使用其声明的策划模式；爆款视频的镜头逻辑（复刻时）以及产品中的事实和注意事项必须保持一致。若版本改变了唯一装填路径、产品结构、审核闸门或视频规格，必须判为无效，不能进入待审核。同一任务的调整或热更新必须新建内容库版本，不能覆盖已审核版本。

## 6. 最简操作

复刻：新建内容策划任务 → 选择策划模式 → 选择产品 → 按模式上传爆款视频/链接或钩子复用素材 → 可选写创作要求 → 指定生成该任务的 v1、v2 或 v3。

原创：未说“复刻”即自动进入原创 → 直接在“产品”表检索产品并读取原创规则；再读取对应内容策划任务的原创专用字段（含叙事节奏），但不通过任务的产品关联来定位产品。不读取复刻素材或改写任务。

原创（母题扩散）：新建内容母题并填写必填项 → 明确要求扩散 → AI 写入创意候选 → 人工入选或自动 Top 1 收敛 → AI 创建一条原创内容策划任务 → 按直接原创流程执行。

系统为指定版本创建或更新内容库记录，再走既有分镜校验和人工审核；“策划模式”本身不等于立即生成成片的授权。

## 7. 最终成片

`最终成片`不是生成队列、审核队列或中间素材库。只有用户对一个已通过的 `内容库` 记录明确下达生成指令，且所有 10 秒段都成功生成、合成为完整目标时长并完成基础技术验片后，才创建一条记录。

| 字段 | 用途 |
| --- | --- |
| `成片名称`、`成片ID` | 成片显示名与唯一标识 |
| `内容版本` | 必填，关联唯一的来源 `内容库` 版本 |
| `最终视频` | 必填，只上传完整、可发布的最终视频 |
| `视频时长（秒）`、`生成时间` | 实际时长和完成时间 |
| `成片路径或预览链接` | 仅在大文件采用分片上传或外部存储交付时补充 |

不得为失败 Job、单个 10 秒分段、重试文件或未验片组装件创建记录。20 MB 以内可由现有附件上传脚本上传；更大文件使用已验证的分片上传或飞书界面上传，并回读确认附件文件名和 token。
