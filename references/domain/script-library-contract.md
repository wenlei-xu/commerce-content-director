# Script library contract

`脚本沉淀库` is a lightweight reusable-template library. It stores complete script templates for retrieval and adaptation; it does not replace the current script's `structured_script` or own the selected product, prop, subject or scene assets.

`参考视频` is optional. When present, it is an active design input for the template, not merely an archive link. Extract and preserve the transferable dimensions that matter to the template: visual style, story structure, camera/viewpoint, shot scale, composition, pacing, transitions, emotional curve and dialogue-function order. Keep those dimensions in the template's content structure or reference notes rather than silently copying source-specific wording, product, logo, subject identity or unsupported claims.

The reference video does not replace `短视频拆解库` or product facts. It does not automatically authorize high-fidelity replication. If the task needs formal source analysis, structure replication or high-fidelity replication, route the video through the applicable source-validity gate and replication workflow first; otherwise use it as a reference-informed original direction.

## Script type

`脚本类型` is a controlled multi-select classification. Use it to describe the template's primary purpose and/or recognizable content genre. Multi-select is intentional because one template may be both commercial and narrative, such as `带货转化` + `悬疑反转`.

Allowed values:

- `带货转化`
- `品牌种草`
- `产品测评`
- `剧情内容`
- `悬疑反转`
- `情绪共鸣`
- `知识科普`
- `生活记录`
- `互动挑战`
- `活动宣传`
- `其他`

Use the smallest accurate set. Do not treat `脚本类型` as a replacement for `适用品类`, `核心问题`, `内容结构` or asset tags. A template's type is retrieval metadata; it does not authorize unsupported product claims or force a narrative shape onto a new script.

## Retrieval

When selecting a reusable template, filter by `脚本类型`, applicable category, product scope, audience and core problem. If the user names a type such as `带货` or `悬疑`, map it to the closest controlled value and preserve any second type when the template genuinely has both functions.
