# 产品动作库契约

`产品动作库`是飞书中的可检索知识表，用来记录某个具体产品已经确认可以怎样拍。它不是工作流、脚本库、分镜候选表或审批替代物。

## 字段

| 字段 | 作用 |
| --- | --- |
| `产品` | 关联现有 `产品` 表；产品硬事实仍以产品表为准 |
| `动作` | 简短的玩法名称，例如“拔河”“叼取”“推动探索” |
| `怎么玩` | 用一句话描述参与者和操作方式 |
| `画面重点` | 写明观众必须看清的接触方式、结构关系或结果 |
| `是否可用` | 只有 `可用` 条目才能进入脚本；`待确认` 和 `停用` 仅供维护 |

每一行代表一个“产品 + 动作”。同一动作可以存在于多个产品，但不能因为产品同类就自动继承。

## 读取规则

1. 读取当前产品的最新产品记录，并确认产品状态为 `可用`。
2. 运行 `python scripts/query_product_actions.py --product-record-id <record_id>`，只使用关联当前产品且 `是否可用=可用` 的条目。
3. 将选中的动作、`怎么玩` 和 `画面重点`写入本次 `structured_script.product_actions` 与对应 Beat；动作库记录本身不拥有脚本时间轴。
4. 产品硬事实、结构、开口、接触路径与禁忌优先于动作库描述。出现冲突时停止并请求修订动作库或确认产品事实。
5. 没有可用条目时不得凭类别常识发明动作；可由人工确认后新增动作库记录，再重新运行脚本流程。

## 写入边界

动作库的维护是独立的知识库变更：创建或修改条目后必须回读记录。脚本生产只读动作库，不在脚本阶段修改动作库。动作库不能改变 `structured_script`、分镜审批状态或最终成片记录。
