# Workflow: dialogue copy

本模块只处理口播，不拥有整份创作稿，也不直接写 Feishu。它可以提出新口播、审查用户提供的口播，或检查口播与画面的关系；采用结果由父流程写回 Markdown 创作稿。

读取产品事实、用户要求、当前创作稿和语言锁。用户明确要求直接使用口播时，逐字保留原文，只允许按 ASR 时间拆分引用。使用脚本库时，把审核通过模板的完整口播复制到创作稿，再做已核实的产品事实替换；保存原文、工作稿和差异。

只有用户明确要求改写、优化、压缩或重新创作，才可以提出措辞改动。建议关注自然口吻、具体痛点、可见证据和 CTA，但不能为了让台词贴合固定画面而强行改写产品事实。

审核结果可以记录：

- 口播是否与产品事实冲突；
- 口播提到的产品、动作或结果是否能在画面中给出证据；
- 是否过度复述操作说明；
- TTS 实际时长和 ASR 是否可用于段落安排。

这些是建议和问题报告，不是另一套脚本字段。完整 TTS 生成后进行 ASR；最终字幕从最终音频产生。中文口播不按字幕行拆成多个 TTS 文件。

`review_dialogue_copy.py` 读取创作稿并输出建议报告；新工作流的结果写入创作稿并由执行记录保存版本。
