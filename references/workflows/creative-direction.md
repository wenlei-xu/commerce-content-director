# Workflow: creative direction

任务开始先确定 `target_spoken_language`：用户指定泰语时用 `th`，指定中文时用 `zh-CN`，未指定时默认 `zh-CN`。写入 `plan/language-lock.json`，并用同一值运行预检。所有生成 Prompt 固定使用英语。

读取一个创作需求、产品、主体池、需要时的场景资产和系统配置。主体池只允许使用 `状态=可用` 且锚点、身份描述完整的主体；场景池只允许使用 `状态=可用` 且有 `场景锚点` 的记录。未显式绑定主体时，按主体轮换策略优先避开最近使用的个体和犬种，不能因为 record ID 排在第一位就反复选同一只狗。需要稳定环境时，按市场、场景类型、动作空间和拍摄质感选择场景，并记录场景资产 ID 与选择理由；场景只约束空间和拍摄语境，不覆盖产品或主体事实。生成多条彼此区分的方向，每条填写人群、状态转变、形式、视角、角度、创意、钩子、异议、说服路径、价值点、证明动作和主要 CTA。方向包必须携带已锁定语言，供后续脚本继承。

写入方向后等待人工选择或自动选择。选择确认后锁定方向。此工作流不生成脚本、首帧或视频。
