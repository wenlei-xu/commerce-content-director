# Workflow: script production

读取一条已锁定创意方向，以及产品硬事实、主体和当前配置。生成本地 structured_script，先运行校验器，再渲染全部审核字段；只有校验通过才创建或更新待审核脚本。

审核意见只修改 structured_script。修订后重新校验和渲染。只有检查通过、审核意见处理完毕的脚本才能锁定。

口播创作额外使用“生活化口播软规则”做评分和改写提示：每句优先 6–14 个字，最长建议不超过 18 个字；一句只表达一个动作或反应；少用“直到、而是、之后、从而”等书面连接词；在画面允许时每隔约 2–3 秒加入“哎”“诶”“你看”“真的掉出来了”等自然反应；台词跟着画面和现场反应说，不写成完整的产品原理说明。软规则不是阻断项，单句超长、偶尔缺少反应或出现连接词都只能产生审核提示，不得单独导致脚本失败。
